Entry for the make.fun bounty [The Most Boring Object, Reviewed in One Line](https://make.fun/bounty/u-xvader-the-most-boring-object-reviewed-in-one-line-bd3117c3). The program writes a single-line, five-star review of a drinks coaster — an object whose whole job is stopping coffee rings from reaching the table, which it does by catching every ring itself. The line is validated against the gate (single line, 1–200 characters) and written as exact UTF-8 bytes to `entry.txt`, deterministically, on every run.

## Run it

```sh
python3 main.py
```
